# E-mails do planê (com a identidade visual)

Cole cada modelo no Supabase: **Authentication → Emails → Templates**.

| Aba no Supabase | Assunto (Subject) | Arquivo para colar no corpo (Body) |
|---|---|---|
| Confirm signup | Confirme seu e-mail no planê | confirmar-cadastro.html |
| Reset password | Sua nova senha do planê | esqueci-a-senha.html |
| Change email address | Confirme seu novo e-mail no planê | trocar-email.html |
| Magic link | Seu link para entrar no planê | link-magico.html |
| Reauthentication | Seu código de confirmação do planê | codigo-confirmacao.html |

Os textos entre {{ }} são preenchidos sozinhos pelo Supabase, não apague.
